# 샘플 양식 (서식)

각 어린이집이 노트북에 두는 **문서 서식 예시**입니다. 데스크톱 앱 설정 화면의
**「양식 폴더 선택」**으로 이 폴더(또는 각자 만든 폴더)를 지정하면, 알림장·보육일지·
발달평가서 초안이 이 서식대로 생성됩니다.

## 규칙

- **파일명에 문서 종류가 들어가야 인식**됩니다.
  - `알림장` → 알림장 / `보육일지`·`일지` → 보육일지
  - `계획안`·`주안`·`월안` → 계획안 / `발달`·`평가서` → 발달평가서
- 지원 형식: `.md` · `.txt` · `.json`
- 본문의 `{키}`는 실제 값으로 치환됩니다. 없는 값은 빈칸으로 지워집니다.

## 치환 가능한 키

| 문서       | 키                                                                                                                                                                |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 알림장     | `{이름}` `{이름_짧게}` `{반}` `{날짜}` `{선생님}` `{보호자}` `{활동}` `{점심}` `{간식}` `{낮잠시작}` `{낮잠종료}` `{낮잠시간}` `{낮잠상태}` `{메모}` `{알레르기}` |
| 보육일지   | `{반}` `{날짜}` `{선생님}` `{등원}` `{결석}` `{활동}` `{관찰메모수}`                                                                                              |
| 계획안     | `{반}` `{선생님}` `{기간}` `{생활주제}`                                                                                                                           |
| 발달평가서 | `{이름}` `{생년월일}` `{반}` `{선생님}` `{관찰수}` `{최다영역}`                                                                                                   |

> 이 폴더는 예시일 뿐이며, 실제 서식은 각 노트북에서 자유롭게 만들어 두면 됩니다.
